# Chess Arena — অনলাইন দাবা ওয়েবসাইট

এই প্রজেক্টে রয়েছে:
- দুইজনের রিয়েল-টাইম অনলাইন দাবা (Socket.IO)
- সার্ভারে দাবার চাল যাচাই (chess.js), বৈধ চাল, কাসলিং, এন পাসাঁ, প্রমোশন, চেক/চেকমেট/ড্র
- রুম তৈরি, রুম কোড দিয়ে যোগ দেওয়া
- মোবাইল-উপযোগী UI, চালের তালিকা, বোর্ড ঘোরানো
- কেবল ডেমো ভার্চুয়াল পয়েন্ট; কোনো অর্থ জমা, বাজি, পেমেন্ট বা নগদ উত্তোলন নেই

## চালানোর নিয়ম
1. Node.js 18 বা তার পরের সংস্করণ ইনস্টল করো।
2. এই ফোল্ডারে টার্মিনাল খুলে চালাও:
   ```bash
   npm install
   npm start
   ```
3. ব্রাউজারে `http://localhost:3000` খোলো।
4. দুই ডিভাইসে একই হোস্ট করা URL খোলা থাকলে একজন Create Room করবে, কোড কপি করে অন্যজনকে পাঠাবে, অন্যজন Join Room করবে।

## ইন্টারনেটে প্রকাশ
- Node.js ও WebSocket/Socket.IO সমর্থন করে এমন hosting দরকার।
- hosting provider-এ `npm install` এবং start command `npm start` সেট করো।
- HTTPS hosting ব্যবহার করো।
- এই ডেমোতে স্থায়ী user account, database, anti-cheat/rate limiting, reconnect recovery, admin tools, বা real-money payments নেই। প্রোডাকশনে প্রকাশের আগে এগুলো প্রয়োজন অনুযায়ী যোগ করতে হবে।
- অর্থ জমা বা নগদ পুরস্কারের ফিচার যুক্ত নয়; পয়েন্ট নগদে রূপান্তরযোগ্য নয়।
